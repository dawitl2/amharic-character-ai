# The Interface 

While our command-line script (`predict.py`) works perfectly for developers, it is not user-friendly. Real users don't type `python predict.py data/ሀ/synthetic_001.png` into a terminal.

We built `gui.py` using Python's built-in `tkinter` library, styled it to resemble a light-mode, modern AI application (like ChatGPT), and integrated our PyTorch model.

### Features
1. **Curated Selection**: Presenting all 6,000 images would crash the UI and be impossible to navigate. Instead, the interface dynamically pulls exactly 5 random images from our vast `data/` folder every time it refreshes. 
2. **Interactive Inference**: The model doesn't just process all images in a loop anymore. It actively waits for the user to select one of the 5 images by clicking on it.
3. **Immediate Feedback**: Once clicked, the UI converts the image to a tensor, runs it through the neural network, applies the Softmax function, and prints the predicted class and confidence percentage beautifully on the screen.
4. **Developer Transparency**: For engineers and reviewers, the bottom of the interface displays the "Developer Details" including the source file, the actual ground truth label, the raw `logits` generated by the PyTorch model, and the mathematical probabilities. 

You can launch this interface right now by running:
```bash
python src/gui.py
```
